#+title: static-assets

static assets and images to be used for different projects

** Fonts

~static-assets/fonts/~ serves the typography every project shares: Work Sans,
Source Serif 4 and JuliaMono, all three libre and all three self-hosted here so
that no page asks a font service for its type. See
[[file:static-assets/fonts/README.md][the font directory's README]] for the file
names, the subsets, the licences and where each family came from.

** Image sizes

For hosting on the web, it is recommendable to resize images to more moderate sizes.

#+begin_src
  mogrify -resize 1386x1040 *.jpg
#+end_src

* AI Policy

This project adheres to the [[https://jointhefreeworld.org/blog/articles/personal/jointhefreeworld-ai-policy/index.html][jointhefreeworld AI (Artificial Intelligence) policy]].

Our core principle is simple: *AI should assist human creativity and problem-solving, never replace human reasoning.*

While tools like Large Language Models (LLMs) and interactive chatbots can be beneficial for reviewing, refactoring small functions, or acting as a sounding board, they should be used with moderation.

We require a human in the loop for all contributions.
